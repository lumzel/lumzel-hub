## 1. 模型脾气与常见翻车原因

- **字面级物理渲染器（写了才有，没写就省）**：MAGI-2 不会像部分模型那样自动脑补未声明的前景虚化遮挡、人物转头过渡或汗珠高光。特写没写背景散景，背景就会糊成单色塑料板；人物没写转头动作，就会僵着脖子平移。
- **上游润色压缩陷阱（Prompt Enhance）**：虽然模型底层支持最高 15,000 字长上下文，但开启默认润色且提示词里塞满空泛形容词（“史诗级、极具视觉张力、无缝承接”）或大段否定排比（“不要光波、不要变形、不要贴图感”）时，上游重写很容易把后半段的精细物理动作和音效要求直接吞掉，甚至把“不要 XX”里的禁用词反向画进画面。
- **时长甜点区**：高密度动作戏、武打与特写表现最稳的区间在 **10~15 秒**；20~30 秒长镜头更适合叙事对话、连续空间横移，或按 `1.5~2.0s` 切分的干脆硬切蒙太奇。
- **声音边界（动作拟音强，多乐器混编易打架）**：MAGI-2 是音画一体架构，金属劈砍、竹干折断、倒冰水、吐小票、盖印章、按键咔哒这类**与画面接触点绑死的瞬态硬拟音**非常准；但如果同时要求“战鼓 + 尺八 + 古筝 + 弦乐”多层背景音乐加音效，经常二选一或糊成一团低动态底噪。需要抓耳配乐时，最稳的做法是提示词里只求干净实录拟音，配乐由代码合成器或 Suno 单独生成后混入。
- **四项看家本领**：亚秒级时间戳硬切（误差约 `±0.20s`）、高速运动下依然锐利无果冻效应的中文排版、非首帧高光构图锚定，以及 `@视频 + 多张 @图片` 的多模态角色解耦控制。

## 2. 八条实战铁律

### 铁律 1：高密度去水 + 符号锚定 + 眼部光源绝对隔离
- 10 秒动作提示词正文控制在 **350~550 个高密度汉字**，只写空间、发力、材质、光影和声音物理变化；客户端支持关闭润色时优先关闭。
- 关键槽位一律用不易被重写吞掉的硬符号：`[0.0s-1.5s]`、`{{Node id}}` / `@图片1`、英文双引号 `"目标中文"`。
- **零否定句**：把所有“不要/禁止/无”改写成正向物理描述。
- **眼部光源绝对隔离禁令**：**严禁把“眼睛 / 瞳孔 / 眼眸 / 目光”与任何带光字眼（月光 / 冷光 / 微光 / 反光 / 映出 / 高光 / 星芒）放在同一个句子里**。实测哪怕写“深褐瞳孔映出一点冷白月光”，模型也会把整颗眼球渲染成通电白炽灯泡。
  - 错误示范：`眼神自然无异常发光` / `瞳孔清晰映出一点冷白月光`
  - 正确写法：`深褐色眼眸冷峻克制、纯黑瞳仁锐利锁死镜头，哑光真实湿润肤质`

### 铁律 2：三段式骨骼发力链 + 跨画幅位移 + 防切头机位
- 地面角色严禁写“保持某姿势高速移动”（会导致双腿不动像踩滑板平移）。
- 必须拆出完整生物力学三段链：**起势蓄力 → 跨步拧腰发力 → 惯性卸力**。
- 强制角色从画框一侧冲入、向另一侧冲出（如`从画面左缘疾步冲入中景，拧腰斜劈后顺惯性向右画框外冲出`），打破原地跑步机感。
- **全身奔跑严禁搭配“贴地机位”**：字面执行贴地机位时，镜头真的只拍靴子和衣摆，人物腰部以上全被切出画外。全身高速移动统一写：`中全景全身侧向高速跟拍（平视偏低机位，完整保留人物头顶至双脚全身入画）`。
- 多人交手避免面对面对称挥刀，改成左右非对称包抄、矮身滑步切入内侧或错身交锋。

### 铁律 3：近景特写强制补齐“前、中、后”三层细节
凡是推到脸部或产品的特写镜头，必须显式写满三层空间：
1. **前景遮挡**：浅景深虚化的前景贴边物（如`前景下缘横置虚化的带水珠暗铁剑刃，随呼吸微晃`）。
2. **中景生理/物理动态**：必须是正在发生的变化而非静态形容词（如`由侧脸猛然转正锁死镜头、鼻翼微张呼出白雾、汗珠顺颧骨滑落、湿发被风吹离额角`）。
3. **后景散景动态**：有纵深光源与微粒运动的背景（如`后景幽暗墨竹散景中飘落细碎雨丝与竹叶`）。

### 铁律 4：音画同句焊接（80% 硬拟音 + 20% 克制低频）
- 不要把所有音效堆在全文末尾，直接焊进产生物理接触的那半句画面里（如`剑刃斜削三根青竹，同步爆出清脆竹干折断声与尖锐金属破空声`）。
- 禁止同时堆砌三种以上配乐乐器。要么声明`全程无背景配乐，突出高清晰物理实录同期声`，要么只保留极简低频脉冲卡在切镜点上。

### 铁律 5：双轨时间切分策略
- **一镜到底 / 甩镜遮挡转场短片**：不写秒数时间戳，用`镜头一 ~ 镜头四`配合前景物理遮挡物（飘带拂过、宽袖横扫、水雾炸开）自然衔接。
- **快节奏广告 / 卡点蒙太奇**：开头直接声明`以下均为成片绝对时间，每个时间边界必须执行干净利落的硬切（Hard Cut），无叠化渐变`，按 `0.1s` 精度切片（如 `[1.2s-2.4s]`），且**每 `1.5 秒` 严格只安排 1 个干脆动作**。

### 铁律 6：非首帧全能参考锚点（打破首帧照搬）
- 在普通首帧模式下，如果中途切走再要求切回正面中近景，模型极易把第 0 帧原封不动贴回来。
- **高阶解法（`reference` 全能参考模式）**：开头声明`@图片1 仅锁定人物五官服饰，并作为镜头二蓄力高光瞬间的构图锚点，严禁作为第 0 帧静止开场`。让开场直接处于实战动态，在第 `3~5 秒` 推入定桩演进到参考图的高光构图，再炸开进入高潮。

### 铁律 7：动态中文绑定实体载体与稳镜窗口
- 所有需要渲染进画面的汉字一律加英文双引号：`"破晓萃取"`、`"灵感暴击"`、`"一杯清醒 ¥28"`。
- 必须绑定真实物理表面、材质与字体粗细（如`白色热敏小票印着端正黑色粗体中文："破晓萃取"`、`牛皮纸袋盖下深红印章中文："灵感暴击"`）。
- 文字出现的镜头给足 `1.5~2.0 秒` 稳镜或缓慢微推，不要叠加剧烈甩镜动态模糊。

### 铁律 8：尾帧保持运动进行时
- 最后一镜严禁出现“停稳、定格、静止、悬停”。让人物压步滑行、衣摆翻涌、水滴滑落或摄影机持续拉远一直延续到最后一帧。
