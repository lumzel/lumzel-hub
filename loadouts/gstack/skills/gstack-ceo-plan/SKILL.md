# gstack Founder / CEO Product Review (`/plan-ceo-review`)

Before accepting a feature request at face value, evaluate whether it solves the real user problem at the right altitude:
1. **Challenge the Premise**: What is the user actually trying to accomplish, and what makes this experience feel effortless ("10-star") instead of merely functional?
2. **Scope Modes**:
   - **Expansion**: Push for the highest-leverage product experience when exploring a new capability.
   - **Hold Scope**: Keep scope tight while maximizing polish and reliability.
   - **Reduction**: Strip to the sharpest MVP slice that proves the core loop today.
3. **Explicit Non-Goals**: Cut features that add cognitive load without compounding user value.
