---
name: spec-first-gate
description: Enforce Spec-Driven Development—clarify ambiguities, lock in contracts, and sequence tasks by user story before implementation.
---

- **Specification Before Code**: Separate *what* the system must do (`speckit-specify`) from *how* it is built (`speckit-plan`). Never bury product requirements inside ad-hoc code changes.
- **Explicit Clarification Markers**: Surface high-impact ambiguities early instead of silently guessing user intent.
- **Independent Story Delivery**: Group implementation tasks by user story (`[US1]`, `[US2]`) so each increment is independently testable and shippable.
