# GitHub Spec-Kit — Specification-Driven Development (SDD)

Specifications are the primary source of truth; code is their expression. Follow the complete 9-skill SDD lifecycle:

1. `speckit-constitution` — Establish or update governing architectural & testing principles.
2. `speckit-specify` — Author testable user stories, functional requirements, and measurable outcomes (WHAT/WHY, no premature tech stack).
3. `speckit-clarify` — Resolve up to 5 high-impact ambiguities before technical planning.
4. `speckit-plan` — Produce technical architecture, data models, contracts, and research decisions.
5. `speckit-checklist` — Validate requirement completeness, clarity, and coverage.
6. `speckit-tasks` — Generate dependency-ordered, user-story-grouped tasks with `[P]` parallel markers.
7. `speckit-analyze` — Run non-destructive cross-artifact consistency analysis across spec, plan, and tasks.
8. `speckit-implement` — Execute tasks phase-by-phase while respecting TDD and task gates.
9. `speckit-converge` — Reconcile implementation drift back into living specifications.
