# Dembrandt Design Extractor

Use this skill when the user wants to extract design tokens from a live website.

- Upstream tool: https://github.com/dembrandt/dembrandt
- Run `npx dembrandt <url>` (or inspect its CLI options with `npx dembrandt --help`) to extract colors, typography, spacing, and borders into structured tokens.
