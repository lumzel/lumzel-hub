0009 Use Redis for Cache Store

One sentence: store the invoice cache in Redis rather than in-process memory.

Context

The service is scaling to 3 instances; in-process caches expire independently and cannot be invalidated globally on write.

Decision

✓ Where to store the cache?
RedisIn-process LRUNo cache
→ Redis
Why: Shared across instances; +1 ms latency is acceptable.

Consequences

EasierHarder
One del after write invalidates globallyLocal development requires running Redis
